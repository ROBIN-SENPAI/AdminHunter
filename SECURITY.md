# Security Policy

## Supported Versions

Only the latest release on the `main` branch receives security updates.

| Version | Supported |
|---------|-----------|
| main (v5.x) | Active |

## Reporting a Vulnerability

This tool is intended for **authorized security assessments only**. If you discover a vulnerability in AdminHunter itself:

1. **Do not** open a public issue.
2. Report privately via GitHub's [Security Advisories](https://github.com/ROBIN-SENPAI/AdminHunter/security/advisories/new) feature.
3. Provide a minimal reproduction: target environment, command used, and expected vs actual behavior.

You will receive an acknowledgment within 48 hours. Responsible disclosure and public credit are guaranteed for valid reports.

## Responsible Use

AdminHunter must only be used against systems you own or are explicitly authorized to test. Unauthorized scanning may violate local laws and the target's terms of service.
